# SmartRoomGuard

Embedded System Lab Final Project

An IoT alarm for a door, drawer, or box lid. An STM32 Nucleo-F411RE reads a reed switch and an ultrasonic sensor and drives a buzzer. A NodeMCU sends status to NETPIE and receives Arm / Disarm / Silence commands from a phone dashboard.
